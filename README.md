# Sculpting the Invisible Gallery

这里是生成式雕塑库的 GitHub Pages 发布文件。

完整项目、声音交互界面、作品存储 API、测试和可回溯开发历史统一保存在主工程仓库
[`WayneWong11/CMAA5016-creating-coding`](https://github.com/WayneWong11/CMAA5016-creating-coding)
的 `SculptingArtworkPickup/` 目录中。

公开部署包含相册首页以及 `/interactive/` 下的声音交互主界面。请在主工程仓库修改源码，再从主工程根目录运行：

```bash
npm run github:publish
```

本公开仓库仅作为无需账号即可访问的 GitHub Pages 发布镜像。
